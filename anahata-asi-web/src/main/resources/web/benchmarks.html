📐 Standard Scoring Criteria

Every challenge is evaluated across 3 weighted categories (100 points maximum):

Accuracy & Safety (50%)

Zero-defect code execution, full requirement completion, thread safety, and zero critical safety violations (e.g. no System.exit() or process crashes).

Developers Score (20%)

Qualitative architectural review by Anahata core developers evaluating code elegance, DRY principles, Javadoc standards, and visual design quality.

Efficiency & Latency (30%)

Time-to-first-token, per-turn execution latency, output token economy, and minimal turn count to complete the prompt.
