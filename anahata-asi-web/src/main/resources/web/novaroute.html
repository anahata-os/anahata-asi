Smart Routing & OpenAI Compatibility

Under the hood, NovaRouteAiProvider extends Anahata's OpenAiChatCompletionsProvider, eliminating vendor SDK dependencies while providing:

  • Single Endpoint (https://novarouteai.com/v1): Unified authentication and billing across all supported Chinese model providers.
  • Automatic Datacenter Fallback: If an upstream provider node experiences latency or rate limits, NovaRouteAI routes requests to healthy nodes automatically.
  • Dynamic Thinking Extraction: Automatically decodes both XML <think> tags and JSON reasoning_content fields directly into Anahata's collapsible thought panels.
