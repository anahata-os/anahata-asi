Anahata ASI Update Center: Universal Cross-Version NetBeans Installer

A lightweight, standalone NetBeans Platform module with zero implementation locks. Provides automated NetBeans version detection, dynamic Anahata ASI Update Center catalog registration (Universal, Stable, and Dev Snapshots), and 1-click installation of Anahata ASI Studio and JavaFX runtimes across all NetBeans versions (NB 21 – NB 35+).

◆ Key Update Center Features

  • Zero Version Lock-in: Relies exclusively on public OpenIDE APIs. Survives NetBeans upgrades without breakage.
  • Dynamic Catalog Routing: Automatically resolves the exact update catalog for your active NetBeans major release.
  • 1-Click Installation: Seamlessly downloads, validates, and installs Anahata ASI Studio from within the IDE.
  • JavaFX Activation: Verifies host JDK JavaFX runtime support and activates the NetBeans JavaFX kit when needed.
  • Legacy Center Cleanup: Detects and removes obsolete update centers from previous NetBeans versions.

Live Interactive Capabilities Showcase (Studio Engine)

Explore the active visual representations of Anahata ASI Studio operating directly inside Apache NetBeans:

[1] Singularity Engine: Dynamic JIT Java Compiler

The model compiles and executes raw Java code directly inside your running NetBeans JVM utilizing our custom child-first ClassLoader. Build, test, and hot-load live tools, Java swing panels, or complex dependency algorithms on-the-fly.

[2] Multimodal Vision: Real-Time Screen & Region Sharing

Share physical screens, specific monitors, or custom rectangular regions with the ASI. Perfect for providing real-time visual feedback on Swing UI renders, layouts, or compiler states.

[3] Atomic Context: Visual Resource Highlighting

Complete visual context awareness. Files loaded into the active AI context automatically light up with a vibrant indicator directly inside the NetBeans Projects, Files, and Favorites views.

[4] Real-Time 3D & Hardware Prototyping (LWJGL)

With built-in LWJGL, GLFW, and OpenGL dependencies, the agent can write, compile, and run raw, real-time 3D rendering windows and game prototypes directly on the host JVM.

[5] Agentic Feedback: Inline AI Code Annotations

Model suggestions, code explanations, and diagnostics are painted dynamically directly onto your source code lines within the NetBeans editor, acting as non-intrusive guide markers.

[6] Self-Healing Filesystem tracking (NbHandle)

Every resource handle in context is bound to a native NetBeans FileObject. If you drag-and-drop, rename, cut, or paste a file across projects, the handle auto-heals and preserves context.

[7] Project Structure & Class Hierarchy Mapping

The model receives structured directory trees of all open source packages, mapping classes, interfaces, records, field modifiers, and precise sizes without expensive directory walking.

[8] Instant Diagnostics & Javac Errors Cache

Continuous, turn-by-turn tracking of workspace health. If a code patch triggers a compilation error, the agent instantly receives the full compiler error stack trace during reloop.

[9] Deep Work Zone: Curated Radio & MIDI Synthesizer

Maintain complete creative focus. Stream high-fidelity internet radio (such as SomaFM, NTS, or KEXP Seattle) directly from NetBeans.

[10] Context Window Garbage Collector (CwGC) Logs

A revolutionary, depth-based context window metabolism. Messages fade gradually depending on their type, and both model and developer can pin or prune parts to support infinitely long sessions.

[11] Human-in-the-Loop Parameter Modification

Complete control over tool execution. View, review, edit, or clear parameters and Java payloads with full syntax highlighting before letting the agent execute them.

[12] Command Center: Granular Security Permissions

Assign Prompt, Always, or Never execution permissions across 180+ stateful JVM tools. Enjoy completely secure, sandboxable coding without blind writes.

[13] Dynamic Provider Registry & Keys Panel

Seamlessly configure multiple API endpoints, tokens, max tokens, and temperature parameters globally across all supported AI providers.

[14] Collaborative NetBeans Terminal (NbTerminal)

Integrated NetBeans terminal tab shared interactively between the developer and the model for subshell collaboration, command execution, and viewport line monitoring.
